### Order, exposure and scoring

repetition uses listed case order, A/B for odd cases and B/A for even; second reverses
case order and arm order. Record each run ID, inputs, settings, reads, actions,
first delivered artifact and any incomplete/error state. No recovery is fed into
other attempts; user-assisted recovery, if later requested, is a separate outcome.

First-attempt primary outcome: all mandatory correctness and scope criteria plus
appropriate transfer for that case, supported by cited artifact/trace locations.
Report per-case outcomes and positive/negative strata; show numerator/denominator
and unknown coverage for each metric. Twelve per-arm attempts are repeated measures
of six tasks, not independent population evidence. Record loaded/read timing when
observable; absence of traces is unknown, not evidence of an unread rule.

Mechanical checks verify source/manifest integrity, artifact presence and explicit
forbidden operations. They cannot grade semantic approach quality. The author
checks concrete oracle evidence, then prepares anonymized matched outputs for user
review without arm labels; randomize presentation and seal the mapping before
review. There is no additional judge model/helper. User review/evaluation effort
belongs in total cost, with unknown resource attribution explicitly marked. No
human correction has occurred merely because a rubric rejects an offline artifact.

Pilot success requires B strictly improving at least one assessed positive matched
pair with no reverse positive pair, all negative/correctness/scope criteria passing
in B, no new correctness/scope loss against A, no critical event and complete
primary evidence coverage. If A is already at ceiling, report no demonstrated
benefit. Missing coverage, mixed gains/losses, reviewer disagreement, or an ungraded
pair yields inconclusive, not success. These conservative small-sample criteria do
not establish statistical generalization. P1.5 separately decides retain/revise/reject.
No permanent adoption follows automatically even after a passing pilot.

Use P0.1 metric denominators: deduplicate parent task/rule/revision opportunities;
retain failed first deliveries; separate steering, new preferences, useful questions
and changed requirements. Count unnecessary work only with requirement-backed
trace evidence, not extra reads/tool count. Permission and false-completion events
are separate incident counts and stop conditions, never averaged away.

### Proposed budget and stop rules

- 24 measured sessions plus at most two disposable preflight sessions; zero automatic
  retries and zero judge-model calls. Tool continuations inside a session remain
  charged to that session; they are not free calls.
- Same Sol/medium/default settings; sequential execution; 120-second per-session
  deadline and 60-minute overall execution wall ceiling including preflight/inspection.
- 1,000,000 reported input tokens (cached tokens are a subset, reported separately)
  and 100,000 output tokens across preflight plus measurement, including failures.
  Check before/after each attempt; a token ceiling is soft by at most one in-flight
  attempt. A hard deadline terminates the process group, records usage as unknown
  if unavailable and starts no replacement. No monetary-price claim is made.
- Stop on any exhausted ceiling, critical permission/false-completion event, model
  mismatch, missing usage, source drift, leaked oracle, previous-run context, or
  inability to restrict tool/file access. Preserve incomplete attempts and evidence.
- Freeze manifest before preflight. Preflight may check a disposable generic task,
  identity/usage and isolation only; it must not tune case answers or oracles. A
  source/protocol change needs an explicit amended manifest before any measured run;
  never silently modify or rebaseline failed evidence.

Preparation/main-author effort is not hidden as free: current task token/time
attribution is unavailable. Report it unknown alongside measured participant totals;
include runner, local checks, grading, retries/failures, user review and analysis in
whole-task accounting where observable. Without these components, no whole-task
cost-saving claim is permitted. Retain pack/manifests/raw run evidence and final
report; scratch mount trees should be temporary, without deleting unique evidence.
