## Risks and limits
Dry-run previews current working-tree changes plus regenerated knowledge indexes. Weekly usage reports and monthly TODO updates are not generated during preview; the command prints this limit. Split-index shared files and external Git object alternates cause safe preview failure. Temporary object copying uses disk proportional to the repository object store. This repository used about 6 MiB of loose objects during verification. The live normal commit/push path was not forced: today's sync was already recorded, and task publication is left to the usual daily sync.
Existing work records are grouped without semantic deletion or truncation; shorter future descriptions rely on the updated one-final-record-per-task convention. Detailed task logs remain authoritative.
