# Fns build restore NU1605, 2026-06-25

## Task

CI restore of `Fns.sln` fails with `NU1605` package downgrade for `FluentMigrator.Runner.Postgres`; find the cause and restore the build.

## Context

Repository `/home/slnnk/git/Fns`, project `migrations/Migrations.Fns/Migrations.Fns.csproj`, CI restore of `Fns.sln`.

## Findings

- `Migrations.Fns.csproj` directly references `FluentMigrator.Runner.Postgres` version `3.2.1`.
- The project references `FluentMigratorCore.Consolisator` version `1.7.0`.
- CI/NuGet did not find `FluentMigratorCore.Consolisator 1.7.0`, resolved approximate version `1.9.0` instead.
- `FluentMigratorCore.Consolisator 1.9.0` depends on `FluentMigrator.Runner 6.2.0`, which depends on `FluentMigrator.Runner.Postgres >= 6.2.0`.
- This conflicts with the direct lower reference `FluentMigrator.Runner.Postgres 3.2.1`, and downgrade warnings are treated as errors (`NU1605`).

Likely fixes:
- Prefer making FluentMigrator packages consistent: upgrade direct `FluentMigrator.Runner.Postgres` to `6.2.0` and validate migrations/runtime behavior.
- Or restore/pin an available package source containing `FluentMigratorCore.Consolisator 1.7.0` if the service must remain on the old FluentMigrator stack.
- Avoid relying on NuGet approximate version resolution for this project.

No code changes were made during this investigation.

### FluentMigratorCore 1.7.0 rebuild plan

User clarified old BaGet repository was removed and `FluentMigratorCore.Consolisator 1.7.0` must be rebuilt from `/home/slnnk/git/FluentMigratorCore` and pushed to Nexus.

Local checks:
- Repo `/home/slnnk/git/FluentMigratorCore` has tag `1.7.0`.
- Tag `1.7.0` points to commit `d11e6c2a`.
- At tag `1.7.0`, `FluentMigratorCore.Consolisator` depends on `FluentMigrator.Runner 3.1.3`, `Npgsql 4.0.0`, `System.Data.SqlClient 4.5.1`.
- At tag `1.7.0`, `FluentMigratorCore.Extensions` depends on `FluentMigrator.Abstractions 3.1.3`.
- `src/Directory.Build.props` derives package version from `CI_COMMIT_TAG`, but local rebuild should also pass `/p:PackageVersion=1.7.0` explicitly.

Recommended command shape:
- checkout tag in detached HEAD
- restore with `NuGet.Config`
- `dotnet pack FluentMigratorCore.sln -c Release -o ./artifacts /p:PackageVersion=1.7.0 /p:CI_COMMIT_TAG=1.7.0`
- push resulting `FluentMigratorCore.*.1.7.0.nupkg` files to Nexus `nuget-private` source, using credentials/API key from secure storage or existing NuGet config; do not record secrets in notes.
